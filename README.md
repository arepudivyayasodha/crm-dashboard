# CRM Dashboard

A responsive and interactive **CRM Dashboard** built using **HTML, CSS, and JavaScript** to manage customer leads efficiently through different pipeline stages.

This project allows users to **add, edit, search, filter, and track leads**, while also providing **conversion analytics** through an interactive dashboard and chart visualization.

---

## Features

- Add and edit customer leads
- Search leads by name or company
- Filter leads by pipeline stage
- Drag-and-drop leads between stages
- Activity tracking for each lead
- Lead conversion to customers
- Dashboard metrics:
  - Total Leads
  - Converted Leads
  - Conversion Rate
- Analytics chart using Chart.js
- Data persistence with Local Storage

---

## Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript** – Functionality
- **app.js** – Analytics visualization

## How It Works

1. Add a lead with name, company, priority, and reminder date
2. Leads enter the **New** stage
3. Move leads through:
   - New
   - Contacted
   - Qualified
   - Converted
4. Track activities for each lead
5. View real-time dashboard statistics
6. Analyze lead status using bar charts
